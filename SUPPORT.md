# Getting help

- **Documentation** — [krizaka.com](https://www.krizaka.com): Orazaka and Orochia docs, synced from the code.
- **Questions and ideas** — GitHub Discussions, one forum per ecosystem:
  - the Java building blocks (`krizaka-build`, `krizaka-platform-kit`, `krizaka-users`, `krizaka-notifications`,
    `krizaka-billing` — they ship as one BOM) → [`krizaka/krizaka-platform-kit`](https://github.com/krizaka/krizaka-platform-kit/discussions);
  - Krizaka UI (`@krizaka/*` on npm) → [`krizaka/krizaka-ui`](https://github.com/krizaka/krizaka-ui/discussions);
  - Orazaka → [`krizaka/orazaka`](https://github.com/krizaka/orazaka/discussions).
- **Why each building block is built the way it is** — [krizaka.com/open-source](https://www.krizaka.com/en/open-source).
- **Bugs and feature requests** — an issue on the repository concerned.
- **Deployments, integrations, partnerships** — the [contact form](https://www.krizaka.com/en/contact).
